Datenschutzerklärung

Stand: 12.10.2026

Zweck der Anwendung

fitness-recoup ist ein privates, nicht-kommerzielles Werkzeug, mit dem der Betreiber ausschließlich seine eigenen Gesundheits- und Fitnessdaten zur persönlichen Auswertung abruft. Daten anderer Personen werden nicht verarbeitet.

Welche Daten verarbeitet werden

Über die Google Health API werden mit reinem Lesezugriff folgende Daten abgerufen: Schritte, Herzfrequenz, Aktivitäten/Trainings, Schlaf, Gewicht, Körperfett sowie optional Ernährungsdaten. Standortdaten werden nicht abgerufen.

Speicherung

Die abgerufenen Daten werden als CSV-Dateien in einem privaten GitHub-Repository des Betreibers gespeichert. Zugangsdaten werden verschlüsselt als GitHub-Secrets hinterlegt.

Weitergabe

Die Daten werden nicht verkauft, nicht an Dritte weitergegeben, nicht für Werbung genutzt und nicht zum Training von KI-Modellen verwendet.

Google API Services User Data Policy

Die Nutzung und Übertragung von Informationen, die über Google APIs empfangen werden, erfolgt gemäß der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Widerruf und Löschung

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden. Die gespeicherten Daten können durch Löschen der Dateien bzw. des Repositorys entfernt werden.
